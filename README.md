# 小跌小買・大跌大買 試算儀表板

一個**純網頁**的股票分批加碼試算工具:輸入台股或美股代碼與資金,自動抓股價,依「距期間高點跌了多少」與「今天跌了多少」,算出這次該投入多少錢、買幾股。另附「交易紀律」與「研究日誌」兩個輔助分頁。

- 線上版:**https://jzx0930.github.io/FinanceCalculator/**
- 資料只存在你自己的瀏覽器(localStorage),不會上傳任何地方。
- ⚠️ 這是把**你自己設定的規則**拿來試算的工具,**不是投資建議**(見文末免責)。

## 1. 快速開始

**最簡單:直接開線上版** → https://jzx0930.github.io/FinanceCalculator/

1. 在「股票代碼」輸入代碼:台股打數字(如 `2330`、`0050`),美股打代號(如 `AAPL`、`VOO`)。
2. 在「總資金」輸入這檔預計最多投入的金額。
3. 按 **查詢並試算**。

之後頁面會每 5 秒自動更新報價並重算(可關閉或改秒數),頂端的發光進度條代表距離下次更新還有多久。

> 換電腦或換瀏覽器也能直接用:報價代理(Worker)網址已內建,不需再設定。

## 3. 加碼試算:操作步驟

### 輸入區
| 欄位 | 說明 |
|---|---|
| 股票代碼 | 台股數字自動判斷上市(`.TW`)/上櫃(`.TWO`);也可輸入完整代碼如 `2330.TW`、`BRK-B`。 |
| 總資金 | 這一檔最多投入的上限。 |
| 標的類型 | **個股(50 階)/ ETF(20 階)**。輸入新代碼時會依 Yahoo 資料自動判斷,也可手動切換(切換會把級距表換成該類型預設)。 |
| 手動輸入股價 | 抓不到報價時勾選,自己填「現價」與「高點」即可照常試算(手動模式不計今日跌幅)。 |
| Worker 網址 | 報價代理,已內建預設值;清空則改用公開代理。 |
| 自動更新 | 預設開啟、每 5 秒(最低 3 秒)。 |

### 報價區(查詢後出現)
```
代碼 2330.TW          市場狀態 ● 盤中               TAI · TWD
現價 / 昨收        → 今日漲跌(對昨收)
現價 / 收盤高點    → 距高點跌幅
[ 跌幅溫度計:刻度是各加碼階門檻,白線是目前跌幅 ]
```
- **市場狀態**:依正常盤時段判斷「盤中/盤前/已收盤/休市」(台股 09:00–13:30、美股 09:30–16:00 當地時間;未含國定假日)。

### 結果區
- **目前落在第幾階**、此階基準單筆金額、剩餘資金。
- **今日是否出手**:未達今日門檻 → 觀望;達標 → 顯示建議買入金額與股數。非盤中時會標示「已收盤・收盤試算」並轉灰,避免誤當成可立即下單。

### 加碼設定卡(可直接修改,自動儲存)
- **② 當天跌幅條件**:今日最小跌幅門檻 + 今日倍數表。
- **① 期間加碼級距表**:高點基準期間(近1月~近5年)+ 各階「期間跌幅 ≥ %」對應「單筆投入 %」。
  表中的「**今日實投**」欄 = 此階金額 × 今日倍率,「約可買(股)」以今日實投計算。

## 4. 運算原理

1. **取資料**
   - 歷史收盤:Yahoo 近 5 年日線(用來算期間高點)。
   - 現價與今日漲跌:**台股用證交所即時報價**,美股用 Yahoo 正常盤價格。

2. **期間高點 H**:所選期間(近 N 天)內的**最高收盤價**。

3. **距高點跌幅**
   ```
   期間跌幅% = max(0, (H − 現價) ÷ H × 100)
   ```
   → 對照級距表,取「門檻 ≤ 期間跌幅」的最深一階,得到 **單筆投入%**。

4. **今日跌幅(相對昨收)**
   ```
   今日跌幅% = max(0, (昨收 − 現價) ÷ 昨收 × 100)
   ```
   - 今日跌幅 < 門檻 → **今日觀望**。
   - 今日跌幅 ≥ 門檻 → 取倍數表中對應的 **今日倍率**。

5. **金額**
   ```
   此階金額   = 總資金 × 單筆投入%
   今日建議買入 = 此階金額 × 今日倍率(上限為總資金)
   股數       = 無條件捨去(金額 ÷ 現價)
   ```

> - 倍數全設為 1 = 純閘門(今天跌夠才買,不加倍)。
> - 切換期間、改級距、改資金都用已抓到的資料**即時重算**,不需重新查詢。
> - 收盤價未還原權息,遇除權息或分割時高點可能略有偏差。

## 5. 預設參數一覽

| 項目 | 預設 |
|---|---|
| 高點基準期間 | 近 1 年 |
| 個股級距 | **50 階**:期間跌幅 1%~50% 每 1% 一階,投入% 指數遞增(每階約 ×1.08),合計 100% |
| ETF 級距 | **20 階**:期間跌幅 1%~20% 每 1% 一階,同樣指數遞增,合計 100% |
| 今日最小跌幅門檻 | 1% |
| 今日倍數表 | 10 階:今日跌 1%~10% → 倍數 ×1 遞增到 ×2.5 |
| 自動更新 | 開啟,每 5 秒 |

所有級距與倍數都可在頁面上修改,並可按「回復預設」還原。這些只是範例設定,請依自己的風險承受度調整。

## 6. 資料來源與即時性

| 市場 | 現價 / 今日漲跌 | 歷史高點 | 即時性 |
|---|---|---|---|
| 台股 | 證交所 MIS 即時報價 | Yahoo 日線 | 盤中約每 5–20 秒更新 |
| 美股 | Yahoo 正常盤價格 | Yahoo 日線 | 接近即時(不含盤前盤後) |

- 瀏覽器無法直接抓 Yahoo/證交所(CORS 限制),所以透過**報價代理 Worker** 轉送。
- 台股即時報價**只能透過自建 Worker**(公開代理會被證交所擋)。
- 收盤後、假日、或冷門股無成交時,價格不動屬正常。

## 7. 部署自己的 Worker(選用)

網頁已內建一支 Worker,一般不需要自己部署。若想用自己的,用指令列部署(約 5 分鐘,免費):

```bash
# 需先安裝 Node.js:https://nodejs.org
cd FinanceCalculator
npm i -g wrangler
npx wrangler login      # 瀏覽器跳出授權頁 → 按「允許」
npx wrangler deploy     # 完成後會印出 Worker 網址
```

把印出的網址(例:`https://stock-proxy.<你的帳號>.workers.dev`)貼到網頁的「資料來源 Worker 網址」欄位即可。
修改 `worker.js` 後再跑一次 `npx wrangler deploy` 就會更新。

Worker 提供兩個端點:

| 端點 | 用途 |
|---|---|
| `?symbol=2330.TW&range=5y&interval=1d` | Yahoo 日線與報價 |
| `?twse=2330` | 證交所台股即時報價(同時查上市與上櫃) |

## 10. 常見問題

**Q. 顯示「台股即時取用失敗,暫用 Yahoo 延遲價」?**
Worker 沒設定或未部署成含台股端點的新版。確認 Worker 網址欄位有值,必要時重新 `npx wrangler deploy`。

**Q. 抓不到報價?**
先確認代碼正確;仍不行就勾「改用手動輸入股價」。

**Q. 收盤後數字不會動?**
正常。只在正常盤時段、且有成交時才會變動。

**Q. 改了預設但畫面沒變?**
你的瀏覽器存有舊設定。按各表下方的「回復預設」即可套用新預設。

**Q. 換裝置設定會跟著嗎?**
Worker 網址會(已內建);級距、資金、日誌等存在各瀏覽器自己的 localStorage,不會同步。重要紀錄可用「匯出 CSV」備份。
