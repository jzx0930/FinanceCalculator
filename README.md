# 小跌小買・大跌大買 試算儀表板

輸入股票代碼(台股或美股)與你的資金,程式抓取股價,並讓你**勾選高點的基準期間**
(近1月／近3月／近6月／近1年／近2年／近5年),依「距該期間**最高收盤價**的跌幅」告訴你該投入資金的百分比。
加碼級距可自訂。純網頁,可直接放上 GitHub Pages。

## 線上使用(GitHub Pages)

`index.html` 在 repo 根目錄,開啟 Pages 後即可線上使用:

1. 把檔案 push 到 GitHub(main 分支)。
2. GitHub repo →「Settings」→ 左側「Pages」。
3. Source 選「Deploy from a branch」,Branch 選 `main`、資料夾選 `/ (root)`,按 Save。
4. 等約 1 分鐘,網站會在 **https://jzx0930.github.io/FinanceCalculator/** 上線。

打開網頁 → 輸入代碼(台股 `2330`、美股 `AAPL`)與資金 → 按「查詢並試算」。

> 網頁版是靠公開 CORS 代理去 Yahoo 抓價(瀏覽器不能直接抓 Yahoo)。代理偶爾會忙碌或失敗,
> 這時勾選「改用手動輸入股價」,自己填現價與 52 週高點即可照常試算。

## 離線 / 本機最穩版(選用)

不想依賴公開代理時,可用內附的本機伺服器直接抓 Yahoo:

- 雙擊 **`start.bat`**(需 Python 3,免裝套件),會自動開伺服器與瀏覽器。
- 從 `http://127.0.0.1:8777/` 開啟時,網頁會優先走本機伺服器抓價,不經過公開代理。

## 用法重點

- 台股輸入數字,如 `2330`(自動試 `.TW` 上市,再試 `.TWO` 上櫃);美股如 `AAPL`、`VOO`;也可輸入完整代碼 `2330.TW`、`BRK-B`。
- 用「高點基準期間」那排按鈕點選要以多久的最高點當基準(可隨時切換,不需重新查詢)。
- 畫面顯示現價、所選期間高點、目前跌幅,並在級距表標出目前第幾階、此階單筆投入多少、累計應投入與剩餘資金。

## 運算原理

1. **取股價**:代碼正規化(台股數字 → `.TW` 上市 / `.TWO` 上櫃;美股原樣),抓 Yahoo 近 5 年日線,得到現價、每日**收盤價**序列與對應日期。
2. **基準高點 H**:依所選期間 N 天,取「最近 N 天內的最高收盤價」。期間越長、納入越早的高點,H 可能越高。
3. **跌幅**:`跌幅% = max(0, (H − 現價) ÷ H × 100)`。創新高時為 0,不會是負。
4. **對照級距**:級距表為「跌幅門檻 → 單筆投入%」。目前階 = 門檻 ≤ 跌幅的最深一階。
   - 此階金額 = 總資金 × 該階%;股數 = ⌊金額 ÷ 現價⌋。
   - 累計應投入% = 門檻 ≤ 跌幅的各階% 相加;累計金額 = 總資金 × 累計%;剩餘 = 總資金 − 累計金額。
5. 換期間、改級距、改資金都用同一份已抓資料**即時重算**,不重新連線。

> 高點採「最高**收盤**價」(非盤中最高)。原始收盤未還原權息,遇除權息或分割可能偏差;必要時可改抓調整後收盤。

## 加碼級距

級距表可直接在頁面上修改(「跌幅 ≥ %」對應「單筆投入 %」),自動存在你的瀏覽器,下次沿用。
預設一組越跌投入越多、各階加總 100% 的級距,可自行增刪調整。
某階金額 = 總資金 × 該階投入%;累計投入 = 目前跌幅已觸發各階投入% 之和。

## 免責

本工具只是把你自訂的規則拿目前股價做試算,**不是投資建議**。向下攤平有風險,
股價可能持續下跌或不再回到高點,請只用你能承受的資金並自行判斷。價格資料可能延遲,下單以券商報價為準。
